# Extensión web
Extensión con un reloj animado que tiene un contador de tienmpo para saber cuanto tiempo pasa de un instante a otro 
## Características
La extensión tiene dos botones uno para empezar y otro finalizar 
el botón Finish llama a un popup con la anumación en grande y el tiempo acumulado  


## Requisitos 
Navegador Mozilla Firefox
Windows 10/11, Linux o macOS
4 GB de RAM

## Instalacción
En la barra del navegador introducir la dirección about:debugging
En el menu de la izquieda seleccionar Este firefox
Cargar complemento temporal y seleccionar la carpeta 


## Ejecucón
En el nevegador en la esquna superior derecha al darle la pieza de puzle debe salir la extensión Reloj
